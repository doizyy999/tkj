What is TKJ Toolkit?

TKJ Toolkit is a collection of practical tools for networking, development, and everyday IT work. It brings the small utilities technicians and developers reach for every day — IP and subnet calculators, encoders, formatters, generators and diagnostics — into one fast, clean website.

Features

  • Fast — built with vanilla HTML, CSS and JavaScript. No frameworks, no build step, instant loads.
  • Privacy-friendly — almost every tool processes your data locally in the browser. Nothing is stored.
  • Free — all tools are free to use, with no accounts and no paywalls.
  • Developer-focused — monospace technical output, one-click copy, dark mode and honest error messages.

How it works

Every tool runs as a static web page. Calculators (IP, subnet, CIDR, color, units) compute results entirely on your device. Generators (passwords, MAC addresses) use the browser's cryptographically secure random number generator. A small number of tools, such as DNS Lookup, call a public API — those cases are clearly labeled on the tool page and in our privacy notice.

Who is it for?

Network technicians (TKJ students and professionals), system administrators, web developers, and anyone who needs a reliable utility without installing software.
