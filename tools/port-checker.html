Port Checker

Understand port checking — and why browsers cannot test arbitrary TCP ports.

About this tool

Honest port checking guidance.

How it works

A static website cannot open raw TCP connections — the browser sandbox forbids it. Rather than show fake OPEN/CLOSED results, this tool validates your host and port, explains the limitation, and gives you the exact commands (nc on Linux/macOS, Test-NetConnection on Windows) to run the check yourself. If you have a server-side API available, it can be wired in here later.
