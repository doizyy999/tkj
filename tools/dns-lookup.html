Query A, AAAA, CNAME, MX, TXT and NS records via DNS-over-HTTPS.

Records

About this tool

Resolve real DNS records from your browser.

How it works

Browsers cannot send raw DNS queries, so this tool uses Cloudflare's public DNS-over-HTTPS API — no keys required and safe for client-side use. Requests are validated, time out after 10 seconds, and errors (invalid domain, API unavailable) are reported clearly. The domain you query is sent to that public resolver; see the privacy page.
