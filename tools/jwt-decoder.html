JWT Decoder

Decode JSON Web Token headers and payloads into readable JSON.

Decoding a JWT does not verify its signature. A token that decodes successfully is not necessarily valid or trustworthy.

About this tool

                
Inspect the contents of a JSON Web Token without sending it to any server.

                
How it works

                
The token is split into its three Base64URL segments. Header and payload are decoded with UTF-8 support and pretty-printed as JSON. Decoding is purely local — the signature segment is displayed as-is and is never verified.
