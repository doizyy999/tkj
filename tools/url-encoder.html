URL Encoder / Decoder

Percent-encode and decode URL components safely with proper error handling.

About this tool

Encode special characters for safe use in URLs, and decode percent-encoded strings.

How it works

Encoding uses encodeURIComponent, which escapes every reserved character. Decoding uses decodeURIComponent and catches malformed percent sequences, showing a clear error instead of breaking.
