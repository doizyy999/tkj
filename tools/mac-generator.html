MAC Address Generator

Generate random MAC addresses in colon, dash, or no-separator format.

About this tool

Generate random 48-bit MAC addresses for testing, virtualization and lab environments.

How it works

Six random bytes are produced with the browser's cryptographically secure random generator (crypto.getRandomValues) when available. With the safety option enabled, the first byte is adjusted to set the locally-administered bit and clear the multicast bit.
