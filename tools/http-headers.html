HTTP Header Checker

Inspect HTTP response headers of a URL, within browser CORS limits.

Browsers restrict cross-origin header access (CORS). Full HTTP header inspection requires a server-side proxy or compatible API. This tool shows exactly what the browser is allowed to read — nothing is faked.

Results

About this tool

See which response headers a server exposes to browsers.

How it works

The tool performs a real fetch() request and reads the headers the response exposes — status code, Content-Type, Server, Cache-Control, Content-Security-Policy, X-Frame-Options and Strict-Transport-Security when visible. Most servers hide headers from cross-origin browser requests; when that happens the tool tells you plainly instead of inventing data.
