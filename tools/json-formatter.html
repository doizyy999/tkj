JSON Formatter

Format, minify and validate JSON data with readable error messages.

About this tool

Pretty-print, compress and check JSON documents.

How it works

Your input is parsed with the browser's native JSON parser. Format re-serializes with two-space indentation; Minify removes all whitespace; Validate reports the parser's exact error message so you can find the problem quickly.
