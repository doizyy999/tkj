HTTP Connectivity Check

Check whether a host is reachable over HTTP(S) and measure response time.

This tool checks HTTP connectivity. It does not perform ICMP ping — browsers are not allowed to send ICMP packets.

Results

About this tool

A browser-safe alternative to ping.

How it works

The tool issues a real HTTP request in no-cors mode and measures how long it takes to resolve. A completed request means the host accepted an HTTP(S) connection; the exact status code is opaque to the browser, and we say so rather than invent one.
